# Basic Calculator (Git & GitHub Practical)

Basic calculator project demonstrating Git branching, merging via Pull Requests, and VS Code Git tools.

## Q1: Git Operations Demonstrated
- `git checkout -b <branch-name>` : Create and switch to a new branch
- `git add .` and `git commit -m "message"` : Stage and commit changes
- `git push origin <branch-name>` : Push branch to GitHub
- Merged branches into `main` using GitHub Pull Requests

## Q2: Separate Branches Merged into Main
- `js-calc` : Built the HTML, CSS, and JavaScript calculator
- `dev` : Added dark mode styling
- Merged both branches into `main`

## Q3: JavaScript Calculator with VS Code Git Tools
- Opened project folder in VS Code
- Used Source Control (`Ctrl + Shift + G`) to stage, commit, and publish branches
- Switched branches using the bottom-left status bar
- Open `index.html` in any browser to run the calculator# calculator
